Шаг 4.2. Добавить единую функцию экономического преимущества
def compute_economic_edge(
    p_win: float,
    executable_ask: float,
    fee_rate: float,
    slippage_rate: float,
) -> float:
    effective_cost = executable_ask * (1 + slippage_rate)
    gross_edge = p_win / effective_cost - 1
    return gross_edge - fee_rate

Для направлений:

UP:   p_win = p_up,      цена = YES ask
DOWN: p_win = 1 - p_up,  цена = NO ask
